Original: https://tympanus.net/Development/TextClipScroll/

License: LICENSE (Codrops MIT). Bundled libraries retain their own license headers.

The effect7 function, clip-6 HTML, font size and CSS rules, texture, GSAP, ScrollTrigger and Lenis are unchanged. The function is exported separately and called once; other effects are not initialized. CSS is the repository original (same lines as live demo). Original smooth-scroll initialization is unchanged. Only font/image readiness and 100vh leading/trailing scroll space are provided by this isolated page. No site header, brand substitution, direction reversal, or six-row layout is applied.

This is a comparison prototype, not the CONCEPT implementation. Header integration is a later step after visual review. Source/assets checked 2026-09-11 against the live demo.
